# 🚀 ChatGPT Prompt Engineering for Developers

Learn how to **harness the power of Large Language Models (LLMs)** to build innovative applications with the **OpenAI API**.  
This short but impactful course is taught by **Isa Fulford (OpenAI)** and **Andrew Ng (DeepLearning.AI)**.  

---

## 📌 Course Overview
This course will equip you with practical knowledge of **Prompt Engineering** — the art of designing effective prompts for LLMs to achieve powerful results. You’ll learn how to **summarize, infer, transform, and expand text**, while mastering best practices for building production-ready applications.  

---

## ✨ What You’ll Learn
- 🧠 **How LLMs work** – an intuitive understanding of the mechanics.  
- 🎯 **Best practices for prompt engineering** – learn 2 key principles to write effective prompts.  
- ⚙️ **Systematic prompt design** – techniques to refine and improve your outputs.  
- 🤖 **Build your own custom chatbot** – integrate LLMs into real-world apps.  

---

## 🔧 Hands-On Applications
The course includes **Jupyter Notebook demos** where you’ll experiment directly with prompts.  

You’ll learn to apply LLMs for tasks such as:
- 📝 **Summarizing** → condense user reviews for brevity.  
- 📊 **Inferring** → perform sentiment analysis & topic extraction.  
- 🌍 **Transforming text** → translation, grammar correction, reformatting.  
- ✍️ **Expanding** → automatically generate emails or long-form text.
